# Student Grade Management System

## Project Overview

The Student Grade Management System is a Python desktop application developed to manage student academic records and calculate overall student performance.

The application allows users to capture, search, update, view, and delete student records while maintaining data persistence through CSV file storage. The system automatically calculates academic performance and provides an easy-to-use graphical user interface built using Tkinter.

This project was developed as part of the Programming in Python module and demonstrates practical software engineering concepts including GUI development, file handling, validation, logging, threading, and exception handling.

---

## Features Implemented

- Add student academic records
- Search for student information
- Update student marks
- Delete student records
- Calculate overall grades
- Display performance summaries
- Input validation
- Error handling and exception management
- CSV-based data storage
- Activity logging
- Multi-threading functionality
- Graphical User Interface (GUI)

## Setup Instructions

### Prerequisites

Ensure Python 3.x is installed on your system.

### Clone the Repository

```bash
git clone https://github.com/P-a-a-r-t-h-M/student-grade-management-system.git
```

### Navigate to the Project Folder

```bash
cd student-grade-management-system
```

### Run the Application

```bash
python main.py
```

### Important

Make sure the following files are located in the same directory:

```text
main.py
student_records.csv
student_log.txt
```

The application reads and writes student records from:

```text
student_records.csv
```

and logs user actions to:

```text
student_log.txt
```
